## 截图规范

1. **真实截取**：所有产品界面截图均来自系统真实运行端到端走查（Playwright / 无头 Chrome CDP 走查产物），严禁使用虚假概念设计图；
2. **脱敏合规**：截图内严禁出现任何真实密码、API Key、私人 Token 或本地开发环境绝对文件路径；
3. **高分保真**：推荐分辨率为 1440 × 900（桌面标准视图）与 390 × 844（移动端标准视图），PNG 格式压缩，文件体积控制在 1MB 以内；
4. **架构图表**：文档内优先使用 GitHub 原生支持的 Mermaid 矢量代码块渲染，兼顾暗黑/明亮模式自适应；如需位图备份，统一使用标准命名（如 `architecture.png`）。
