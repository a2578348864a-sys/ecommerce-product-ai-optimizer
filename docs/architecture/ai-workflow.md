# AI 工作流

## 研究分析

单个商品的「一键分析」由 Agent 编排执行四层研究：

| 层 | 输出 |
| --- | --- |
| sourcing | 供应商结论、价格信号、可用性信号、假设与缺口 |
| risk | 合规、侵权、供应链、物流、安全风险标记 |
| summary | 目标用户、核心卖点、疑虑 |
| listing | 标题草稿、要点草稿、图片建议 |

研究完成后生成可验证的研究记录（research record），包含哈希校验与版本。

## 创作交接（Creative Handoff）

AI 研究与内容创作之间的桥梁：

1. 研究记录满足条件后生成「创作候选」
2. 用户确认哪些商品事实可进入创作
3. 已确认事实形成「权威创作输入」
4. Listing 与 Image Studio 均基于同一份确认事实

未确认的信息（含市场信号）不进入权威创作输入。

## Listing 生成

- 输入：已确认商品事实 + 关键词 Brief
- 过程：AI 生成标题与要点 → 质量校验器校验（长度、政策边界）→ 通过则保存草稿，不通过则降级为安全草稿
- 输出：三态草稿（安全事实草稿 / 结构化草稿 / AI 优化草稿）

## 图片生成

- 输入：共享确认事实 + 已批准的视觉参考（可选）+ 场景预设
- 模式：`composition_concept`（无参考图）或 `product_visual_draft`（有批准参考图）
- 输出：图片草稿，供人工选择与复核

## 人工确认节点

| 节点 | 动作 |
| --- | --- |
| 研究决定 | 继续 / 待补 / 放弃 |
| 事实确认 | 勾选可进入创作的事实 |
| 参考图批准 | 使用研究主图作为视觉参考 |
| 草稿复核 | 最终人工复核后使用 |
