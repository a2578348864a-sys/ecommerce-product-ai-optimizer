# 历史归档

本目录保存 project-001 的历史版本、阶段性报告、浏览器证据、原型输入和内部冻结记录。

> **历史材料，仅用于项目演进记录，不代表当前生产架构。**

| 目录 | 内容 | 权威性 |
| --- | --- | --- |
| `releases/` | v3、v3.1、v4、v4.1 的历史 Markdown 文档 | 非当前规范 |
| `evidence/` | 历史截图、HTML、TXT 与验收记录 | 非产品数据 |
| `prototypes/` | 原型 JSON、试验输入与回放数据 | 非生产数据 |
| `internal/` | 脱敏后的内部冻结记录 | 非当前运行基线 |
| `old-design/` | 更早期的设计与 Alpha 记录 | 非当前规范 |
| `phase-reports/` | 早期阶段报告和验收记录 | 非当前规范 |

当前产品说明、安装方式和运行边界以根目录 [README.md](../../README.md) 与 [docs/README.md](../README.md) 为准。
