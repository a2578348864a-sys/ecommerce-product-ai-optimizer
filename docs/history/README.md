# docs/history — 历史归档目录

本目录存放**从首页（README）移出的历史版本说明**，目的是让仓库首页只呈现当前稳定版本，同时不丢失任何历史内容。

## 目录内容

| 文件 | 内容 |
| --- | --- |
| `listing-v5-freeze-notes.md` | Listing V5.1 / V5.7 阶段性说明、基准数据与 Validator 修复记录 |
| `v4-langgraph-experiment.md` | V4 / LangGraph 实验链说明（feature-flagged，非当前主链） |

## 约定

- 历史文件**只增不改写**：如需修正结论，请新增说明段落并标注日期，不要改写当时的事实记录。
- 本目录**不是**历史文档的唯一位置：`docs/v3*`、`docs/v4*`、`docs/listing-v5/`、`docs/archive/`、`ops/` 中的历史材料保留在原路径（被 50+ 处交叉引用），统一由 [../HISTORY.md](../HISTORY.md) 登记索引。
- 首页与当前状态入口：[../../README.md](../../README.md)、[../PROJECT_STATUS.md](../PROJECT_STATUS.md)。
