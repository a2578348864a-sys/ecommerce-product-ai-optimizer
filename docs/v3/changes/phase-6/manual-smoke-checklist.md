# V3 Core 最终人工验收 — 用户操作版 Smoke 清单

> 目标：验证「一个不熟悉跨境电商的新手，把真实商品放进工作台后，能否真正理解现在知道什么、不知道什么、最大风险、为什么、下一步该研究什么」。
> 本清单不需要你懂代码、数据库或任何工程术语。全程只需：打开浏览器、按步骤点、看页面、记录你看到的东西。
> 判定：由**你本人**根据实际体验给出结论（不是由 AI 代替你判断"好不好用"）。

---

## 开始前（2 分钟）

1. 打开浏览器，访问：`http://localhost:3005`
2. 输入访问密码登录（如果还没有密码，告诉我，我按现有规则协助生成演示访问）。
3. 登录后你应该看到"工作台"首页，顶部有：发现商品 / 待研究商品 / 研究历史 / Listing Studio / Image Studio。
   - ✅ 正常：看到以上五个入口。
   - ❌ 异常：页面打不开或报错 → 记录错误信息，暂停。

> 真实商品素材：请使用材料根 `D:\Workspace\projects\project-001-跨境电商AI工具\XLSX案例\` 里的两个文件：
> - `Products(10)-US-20260814.xlsx`（10 个真实商品的搜索报表）
> - `KeywordMining-US-owala(10)-20260815.xlsx`（关键词挖掘报表，可选）

---

## 第 1 步｜把真实商品放进来（发现商品）

**操作**：点左侧「发现商品」→ 上传 `Products(10)-US-20260814.xlsx` → 按提示确认报表类型（系统可能请你选择"搜索报表 / 类目报表"）→ 确认。

**正常应该看到**：页面列出 10 个商品（每个有标题、价格、评分等信息），不会报"无法识别"。

---

## 第 2 步｜挑一个商品进入研究池（候选）

**操作**：从列表里**只选 1 个**商品（建议选一个你没听说过的，比如某个你不认识的品牌）→ 加入"待研究商品"。

**正常应该看到**：这个商品出现在「待研究商品」列表里，只有这一个，没有混进别的商品。

**这里要特别留意（验收点 A：商品身份）**：
- 后面每一步，页面上显示的商品名称/图片，是不是始终是同一个商品？
- 有没有任何一步出现"另一个商品的数据"？

---

## 第 3 步｜打开商品研究页，看"证据工作台"（发现商品 → 商品研究）

**操作**：在「待研究商品」里点这个商品 → 开始研究（如果按钮叫"一键分析"或"开始研究"就点它）→ 等它跑完 → 从「研究历史」打开这个商品的任务详情。

**正常应该看到**（从上到下）：
1. **简明结论**：用大白话写的"目前知道什么 / 不知道什么 / 人工决定 / 下一步"。
2. **商品概览**：图片、ASIN、标题、品牌、价格、评分、评论数、BSR、估算销量等；每项带小标签：`快照` / `估算` / `未知`。带"估算"的项旁边有"第三方估算，非平台后台数据"提示。
3. **竞品 Evidence**（未维护会显示"未维护"，正常）。
4. **关键词 Evidence**（第 4 步导入后才有内容）。
5. **货源 Evidence**：显示"Core 阶段货源证据未收集"（正常，这不是错误）。
6. **还缺什么（Missing）**：采购价 / MOQ / 物流成本 / 合规 都显示 unknown。
7. **AI 证据总结**（第 5 步生成）。

**这里要特别留意（验收点 B+C：可理解性）**：
- 不看那些专业指标（BSR、SPR、供需比…），只看最上面的"简明结论"区，你能说出：
  - 现在知道什么？
  - 不知道什么？
  - 最大风险？
  - 为什么？
  - 下一步该研究什么？
- 如果必须读懂 BSR/SPR 才能明白，请如实记录"看不懂"。

---

## 第 4 步｜导入关键词证据（可选，但推荐做）

**操作**：在任务详情页「关键词 Evidence」区 → 上传 `KeywordMining-US-owala(10)-20260815.xlsx` → 看预览 → 确认保存。

**正常应该看到**：出现关键词表格（关键词、相关度、ABA 排名、月搜索量、购买率、供需比、PPC 价格等）。"购买率"显示为百分比（如 0.3%），"供需比"是数字（如 1296.2，不是 129620%）。

---

## 第 5 步｜生成 AI 证据总结（核心验收）

**操作**：在任务详情页「AI 证据总结」区 → 点「生成 AI 证据总结」→ 等待生成（可能需要十几秒到一分钟）。

**正常应该看到**：
1. **AI 解释（新手可读）** 五条：现在知道什么 / 不知道什么 / 最大风险 / 为什么 / 下一步研究什么。
2. 分类条目：已确认事实 / 估算 / 支持信号 / 风险 / 缺失 / 下一步，每条都有"X 条引用"标记。
3. 顶部徽章"EvidenceRef 门禁通过"。

**这里要特别留意（验收点 E：AI 不胡编）**——用下面的《AI 抽查四问模板》至少抽 4 条。

---

## 第 6 步｜做人工决定（人说了算）

**操作**：在研究页/任务详情找到人工决定区 → 选择：`待补信息` / `进入创作准备` / `放弃研究` 之一（选哪个都行，这是测试）→ 可填一句原因 → 保存。

**正常应该看到**：决定保存成功，页面顶部/状态区更新为你选的决定。系统**不会**自动替你继续任何事。

---

## 第 7 步｜进入内容制作（确认事实 → 创作交接）

**操作**：按页面提示勾选"哪些事实可以用于创作"（比如商品材质、尺寸、卖点）→ 创建创作交接（按钮可能叫"确认并进入创作准备"）。

**正常应该看到**：已确认的事实进入创作输入；**没确认的信息不会进入**；页面上有"需人工复核"的标注。

---

## 第 8 步｜生成 Listing 草稿

**操作**：进入 Listing Studio（或在任务内点"生成 Listing 草稿"）→ 生成。

**正常应该看到**：标题、卖点要点、描述草稿。页面明确标注这是草稿、**不会自动上架**、需人工复核。草稿内容基于你确认过的事实。

---

## 第 9 步｜生成图片草稿

**操作**：进入 Image Studio（或在任务内生成）→ 生成图片草稿。

**正常应该看到**：图片草稿生成，标注需人工复核后才能使用。

---

## 验收点 D｜Score 会不会误导你

在「待研究商品」列表和商品概览区，可能看到一个分数（如 87 分 / 63 分）。

**请如实回答**：
- 看到分数时，你的第一反应是不是"分数高 = 更值得卖"？
- 页面上的分数旁边有没有"参考 / 旧兼容排序信号，不代表值得卖"这类说明？
- 如果你觉得它像"推荐分"，请记录——这是需要修正的产品问题。

---

## AI 抽查四问模板（验收点 E，至少抽 4 条）

从 AI 证据总结里挑 4 条代表性输出（建议：1 条"已确认事实"、1 条"估算"、1 条"风险"、1 条"下一步"），逐条回答：

| 问题 | 第 1 条（事实类） | 第 2 条（估算类） | 第 3 条（风险类） | 第 4 条（下一步） |
|---|---|---|---|---|
| 1. 它说了什么（原句抄下来） | | | | |
| 2. 页面上能找到对应数据吗（证据是否真的支持） | | | | |
| 3. 数字和页面数据一致吗（有没有变数字） | | | | |
| 4. 它有没有比证据更"肯定"（估算说成事实？不知道的给你填了？） | | | | |

**特别检查**：AI 输出里有没有出现——
- ❌ "值得做 / 不值得做"
- ❌ "爆款概率"
- ❌ "推荐指数 / 综合评分"
- ❌ 编造采购价、合规结论等没有任何证据的数字或结论

出现任何一条 → 记录原文，这是 FAIL 信号。

---

## 验收点 F｜下一步建议

**请回答**：AI 总结里的"下一步研究什么"，是"建议你去补什么证据"（如：补供应商信息、补合规确认），还是"替你做决定"（如：这个可以做/不要做）？

- 前者 = 正常（符合设计）
- 后者 = 记录原文，这是 FAIL 信号

---

## 你最终只需要回答的验收问题（汇总）

请回答以下 6 个问题（可以大白话，如实即可）：

1. **主链能跑通吗**：从导入商品到 Listing/图片草稿，有没有哪一步走不下去？
2. **商品串没串**：全程是不是始终同一个商品，有没有看到别的商品的数据？
3. **数据来源对吗**：价格、评分这些数字，看起来是真实报表里的，还是像编的？
4. **新手能看懂吗**：不看专业指标，你能说出"现在知道什么、不知道什么、最大风险、为什么、下一步该研究什么"吗？
5. **AI 有没有胡编**：抽查的 4 条里，有没有"数字变了 / 没证据硬说 / 比证据更肯定 / 替你做了决定"的情况？
6. **分数有没有误导你**：会不会把某个分数当成"更值得卖"？

---

## 判定规则（由你给出结论）

- 如果：主链跑通 + 商品不串 + 数据正确 + AI 不胡编 + 新手能看懂 + 知道下一步 → 结论写：**MANUAL_CORE_SMOKE = PASS**
- 如果：技术链都通，但你仍然觉得"数据很多，但还是看不懂这个商品现在是什么情况" → 结论写：**MANUAL_CORE_SMOKE = FAIL_PRODUCT_COMPREHENSION**（这不算失败，是产品修正信号，我会只给最小修正建议，不重开 V3 Core）
- 如果中途有步骤走不下去/报错 → 记录第几步 + 错误信息，暂停并告诉我。

> 你的验收结果将决定：Core 是否最终产品验收通过，以及是否执行 main → origin/main 推送。在你完成并给出结论前，我不会 push、不会进入 V3.x、不会继续写新功能。
