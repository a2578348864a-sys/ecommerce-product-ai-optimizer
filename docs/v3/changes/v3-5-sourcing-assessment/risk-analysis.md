# V3.5 — Risk Analysis（对抗式审查）

> 任务书四节：优先找风险，而不是优先证明方案可行。

## 1. 24 项风险逐条评估

| # | 风险 | 评估 | 防制设计 |
|---|---|---|---|
| 1 | "看起来像同款"其实规格不同 | **真实高风险**（规格是匹配的核心，页面规格常不完整） | 关键规格缺失 → 只能 unknown/likely_similar，禁止 exact_match（任务书十四节） |
| 2 | 主图相似但不是同一商品 | **真实高风险** | 图片相似不能单独证明同款；图片只作展示参考 |
| 3 | 页面价格只是最低规格价格 | **真实高风险** | "¥x 起" → 保存为 priceRange/displayedPrice + nature=Page Snapshot，禁止当采购成本（任务书十六节） |
| 4 | 阶梯价格需结合起订量理解 | **真实风险** | 阶梯价与起批量成对保存，禁止拆开解读 |
| 5 | SKU 选择改变价格 | **真实风险** | 价格必须绑定 SKU 上下文（specs 字段） |
| 6 | 促销价不是长期采购价 | **真实风险** | 促销价标注 DISPLAY_ONLY；不推断长期价 |
| 7 | ¥9.9 起不代表目标规格 ¥9.9 | **真实高风险** | "起"价语义在 UI 明示；禁止换算 |
| 8 | MOQ 按件/箱/颜色/规格计算 | **真实高风险** | MOQ 不归一化；保存 displayedMOQ 原文 + source snippet（任务书十七节） |
| 9 | 定制 MOQ 与普通采购 MOQ 不同 | **真实风险** | 定制 MOQ 属 Seller Claim，需询盘 |
| 10 | 运费未包含 | **真实风险** | 页面价不含运费；运费字段 CONDITIONAL |
| 11 | 国内运费 ≠ 跨境物流 | **真实高风险** | 跨境物流 = Unknown（任务书十九节） |
| 12 | 含税/未税口径不明确 | **真实风险** | 口径不明 → unknown；不假设含税 |
| 13 | 支持一件代发 ≠ 适合跨境 | **真实风险** | 代发是 Seller Claim；跨境适配 = Unknown |
| 14 | 供应商评分 ≠ 供应可靠性 | **真实高风险** | 平台指标只展示为 Platform Metadata；禁止推导"可靠"（任务书十八节） |
| 15 | 店铺年限 ≠ 履约能力 | **真实风险** | 年限 = 展示；不推导 |
| 16 | 页面销量 ≠ 供应稳定性 | **真实风险** | 销量 = Platform Metadata；不推导 |
| 17 | 认证图片 ≠ 认证真实有效 | **真实风险** | 认证 = Seller Claim；核实 = 询盘/人工 |
| 18 | 材质描述营销化 | **真实风险** | 材质 = Seller Claim；与 Amazon 侧材质（若 V3.4 有）对比为 Derived |
| 19 | AI 把相似商品错误绑定 | **真实高风险** | 匹配合同：exact/likely_similar/partial/different/unknown；无 AI 概率评分（任务书十五节） |
| 20 | 1688 页面登录/风控/动态渲染 | **实测确认（登录墙）** | 不绕过；人工导入路径（browser-feasibility.md） |
| 21 | Browser 环境看到不同价格/内容 | **风险存在**（未实测——登录墙阻断） | 页面快照标注 capturedAt；不跨环境混用 |
| 22 | 页面结构变化 | **风险存在** | 若未来做浏览器采集需版本化提取器；当前人工导入无此风险 |
| 23 | 搜索结果大量广告/非相关 | **风险存在** | 不实现自动搜索（方案 A 不做）；用户人工选候选 |
| 24 | AI 为"帮用户"输出利润结论 | **真实高风险** | AI 输出白名单禁止利润/推荐/合规（任务书二十三节） |

## 2. 最高风险排序（Top 5）

1. **同款/相似款误判**（#1/#2/#19）——匹配合同 + 无概率评分 + 关键规格缺失降级
2. **价格语义误导**（#3/#7）——displayedPrice/priceRange/unknown 三态 + 禁止当成本
3. **MOQ 语义误解**（#8/#9）——不归一化，保留原文
4. **供应商指标推导可靠性**（#14/#15/#16）——只展示平台标记，禁止推导
5. **AI 输出利润/推荐**（#24）——输出白名单 + 复用 V3.4 的 evidenceRefs/fail-closed 模式

## 3. 停止条件对照（任务书三十八节）

| 条件 | 当前状态 |
|---|---|
| 1. 必须绕登录/CAPTCHA | **触发**（1688 登录墙实测）→ 不绕；降级人工导入 ✓ |
| 2. 页面无法稳定绑定 offer/entity | 未实测（登录墙阻断）；人工导入时 offerId 由用户提供 → 可绑定 |
| 3. 页面价格无法区分语义 | 可防制（三态保存） |
| 4. 规格无法可靠读取 | 可防制（缺失 → unknown） |
| 5. 同款判断高度依赖 AI 猜测 | **部分触发** → 设计上禁止 AI 概率，匹配合同人工可判 |
| 6. 必须大规模爬站 | 不触发（不爬） |
| 7. 必须接入高成本/封闭数据源 | 官方 API 门槛高 → 不作为当前前提 |
| 8. 必须重建供应链 Agent | 不触发（明确不重建） |
| 9. 必须假装知道真实物流/成本 | 不触发（全部 unknown） |
| 10. 只能输出"推荐供应商"无真实依据 | 不触发（无推荐） |

**结论**：主要风险（登录墙/同款误判/价格误导）均可通过「人工导入 + 三态语义 + 匹配合同 + 无 AI 评分」防制；**不触发 NOT_ADOPTED 级失败**，但明确限制自动化范围。
