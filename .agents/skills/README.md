# .agents/skills — AI 编码助手技能目录（工具约定）

本目录存放**开发期 AI 编码助手**使用的可复用技能（skill）定义，遵循 `.agents/` 目录约定。它**不参与应用运行时**，不影响 3005 服务与任何产品功能。

## 本目录内容

| 名称 | 用途 |
| --- | --- |
| `amazon-product-research/` | Amazon 商品研究相关的助手技能定义 |
| `sellersprite-market-preview/` | SellerSprite 市场预览相关的助手技能定义 |

## 为什么仓库里有三个 skills 目录？

公开仓库里同时出现 `.agents/skills/`、`.claude/skills/`、`skills/` 容易让人困惑，说明如下：

| 目录 | 面向 | 说明 |
| --- | --- | --- |
| `.agents/skills/` | 通用 AI 编码助手（`.agents` 约定） | 本目录。工具自动发现路径 |
| `.claude/skills/` | Claude Code | 该工具自己的发现路径，内容为其可用子集 |
| `skills/` | 仓库自有技能包 | 项目维护的技能源目录，可包含尚未分发到各工具路径的内容 |

三处**按各自工具的发现约定分别存放**，因此存在同名目录的重复；这是工具要求，不是冗余错误。修改某个技能时请同时检查是否需要同步到其他两处。

> 技能定义的具体字段与用法以各子目录内的文件为准（保持原名称、目录与入口不变）。
